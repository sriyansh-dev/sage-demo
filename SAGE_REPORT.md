## Code review

The repository provides basic inventory utilities and configuration loading but contains several correctness and security flaws. Core functions miscalculate values and lack edge‑case handling, while the YAML loader uses an unsafe API. Tests fail due to incorrect implementations, and the shell utility poses command‑injection risks. The codebase is small and readable, but robustness and safety need improvement.

**Strengths**
- Simple, well‑documented functions make the intent clear
- Low cyclomatic complexity makes the code easy to follow
- Tests are present for key functionality

| Severity | Location | Issue | Suggestion |
|---|---|---|---|
| high | `inventory.py` | `total_price` ignores item quantity, summing only `price` fields, leading to incorrect totals | Multiply each item's price by its quantity, e.g., `total += item['price'] * item.get('qty', 1)` |
| high | `inventory.py` | `apply_discount` computes the discount amount instead of the final price | Return `round(price * (1 - percent/100), 2)` to reflect the discounted price |
| high | `inventory.py` | `average_price` divides by `len(items)` without checking for an empty list, causing ZeroDivisionError | Return `0.0` when `items` is empty or guard the division with a conditional |
| high | `config.py` | Uses `yaml.load` without specifying a loader, which is unsafe and can lead to arbitrary code execution | Replace with `yaml.safe_load(f)` or explicitly pass `Loader=yaml.SafeLoader` |
| high | `shell_utils.py` | Executes shell commands directly (e.g., via `os.system` or `subprocess` without sanitization), opening command‑injection vulnerabilities | Use the `subprocess` module with `list` arguments and avoid passing unsanitized user input; consider using `shlex.quote` if a string command is required |

**Optimization opportunities**
- Cache the result of `sum(i['price'] for i in items)` in `average_price` to avoid recomputation if used elsewhere
- Use list comprehensions or generator expressions consistently for readability
- Add type hints to functions for better maintainability and static analysis

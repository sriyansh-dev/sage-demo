## Code review

The repository provides a small inventory toolkit and configuration loader, but contains critical bugs and security flaws. The `total_price` function ignores quantities, leading to incorrect totals, and `average_price` can raise a ZeroDivisionError on empty input. YAML loading uses unsafe `yaml.load`, and `list_dir` likely invokes a shell command unsafely. These issues cause test failures and pose security risks. Refactoring the functions and fixing unsafe operations will improve correctness, safety, and maintainability.

**Strengths**
- Simple, well‑documented code base makes it easy to understand the intended behavior
- Small module size and low cyclomatic complexity aid readability
- Tests cover key edge cases such as paths with spaces

| Severity | Location | Issue | Suggestion |
|---|---|---|---|
| high | `inventory.py` | `total_price` adds only `item["price"]` and ignores the `qty` field, producing wrong totals and causing test failures | Multiply each price by its quantity: `total += item["price"] * item.get("qty", 1)` |
| high | `inventory.py` | `average_price` divides by `len(items)` without handling an empty list, raising ZeroDivisionError | Return 0.0 when `items` is empty or guard the division with a conditional |
| high | `config.py` | Uses `yaml.load` without specifying a loader, which can execute arbitrary code from crafted YAML files | Replace with `yaml.safe_load` or explicitly pass `Loader=yaml.SafeLoader` |
| high | `shell_utils.py` | `list_dir` likely builds a shell command string and executes it, exposing command injection and mishandling of spaces | Use Python's `os.listdir` or `pathlib.Path.iterdir` instead of invoking a shell |
| medium | `inventory.py` | `apply_discount` computes `price * percent / 100` which returns the discount amount, not the discounted price | Return `price - round(price * percent / 100, 2)` or rename the function to reflect its purpose |
| low | `inventory.py` | Functions lack type hints and docstring examples, reducing IDE assistance and future maintainability | Add type annotations and richer docstrings |

**Optimization opportunities**
- Iterate with a generator expression in `total_price` for slight speed gain: `sum(item["price"] * item.get("qty",1) for item in items)`
- Use `pathlib.Path` throughout the project to simplify path handling and avoid string concatenation
- Cache the loaded configuration if it is read repeatedly, e.g., with `functools.lru_cache`

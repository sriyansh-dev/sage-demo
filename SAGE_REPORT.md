## Code review

The repository provides a small inventory utility, configuration loader, and shell helper, but contains critical bugs and security flaws. Core functions miscalculate values and lack input validation, while the config loader uses unsafe YAML loading and the shell utility executes commands unsafely. Tests fail due to incorrect logic in total_price and average_price, and the list_dir implementation is missing. Addressing these issues will improve correctness, security, and maintainability.

**Strengths**
- Simple, well‑documented functions with clear intent
- Low overall code complexity makes it easy to understand
- Comprehensive test suite covering edge cases

| Severity | Location | Issue | Suggestion |
|---|---|---|---|
| high | `inventory.py` | total_price adds only the price field, ignoring quantity, causing incorrect totals; also returns rounded value before full sum may lead to precision loss | Multiply each item's price by its 'qty' field and sum, then round the final total |
| high | `inventory.py` | average_price divides by len(items) without handling empty list, raising ZeroDivisionError | Return 0.0 when items is empty before performing division |
| high | `config.py` | Uses yaml.load without specifying a SafeLoader, which can execute arbitrary code on malicious YAML input | Replace yaml.load(f) with yaml.safe_load(f) or yaml.load(f, Loader=yaml.SafeLoader) |
| high | `shell_utils.py` | Executes shell commands via os.system or subprocess without sanitizing input, leading to command injection vulnerabilities | Avoid shell=True; use subprocess.run with a list of arguments and validate paths |
| medium | `inventory.py` | apply_discount calculates discount amount instead of discounted price (price * (1 - percent/100)) | Return round(price * (1 - percent/100), 2) |
| medium | `shell_utils.py` | list_dir implementation missing; test expects it to return filenames without the directory component and handle spaces | Implement list_dir using os.listdir and sort results, ensuring it works with paths containing spaces |
| low | `inventory.py` | Docstrings are minimal and could include parameter/return type information | Expand docstrings to follow PEP 257 conventions |

**Optimization opportunities**
- Use generator expressions with sum() for total_price and average_price to reduce temporary variables
- Cache the result of yaml.safe_load if config files are large and reused
- Return sorted list from list_dir for deterministic test results

The repository provides a small inventory utility and a CLI that reports stock values, but several logic errors and security concerns undermine its reliability. Tests fail because the authentication helpers depend on environment configuration not covered here, and the codebase would benefit from clearer structure and error handling.

**Strengths**

| Severity | Location | Issue | Suggestion |
|---|---|---|---|
| high | `inventory.py` | total_price sums only item['price'] and ignores 'qty', producing an incorrect total value | Multiply price by quantity: total += item['price'] * item.get('qty',1) |
| high | `inventory.py` | apply_discount calculates price * percent / 100, returning the discount amount instead of the discounted price | Return price - round(price * percent / 100, 2) or price * (1 - percent/100) |
| high | `inventory.py` | average_price divides by len(items) without handling an empty list, raising ZeroDivisionError | Return 0.0 when items is empty: if not items: return 0.0 |

| low | `main.py` | Key status message reveals whether an environment variable is set, which may be unnecessary information in production logs | Consider removing or masking the key status output in production |

## Code review

The repository provides a small inventory utility and configuration loader, but contains critical bugs and security flaws. The `total_price` function ignores quantities, `average_price` can raise ZeroDivisionError, and `apply_discount` miscalculates the discount. YAML loading is unsafe and shell utilities execute commands without sanitization. Tests fail due to these logic errors and missing handling of spaces in paths.

**Strengths**
- Simple, well‑documented functions with clear docstrings
- Small codebase makes it easy to audit
- Tests cover basic functionality for config loading and shell utilities

| Severity | Location | Issue | Suggestion |
|---|---|---|---|
| high | `inventory.py` | `total_price` adds only `item["price"]` and ignores `item["qty"]`, producing incorrect totals. | Multiply price by quantity: `total += item["price"] * item.get("qty", 1)` |
| high | `inventory.py` | `average_price` divides by `len(items)` without checking for an empty list, causing ZeroDivisionError. | Return 0.0 when `items` is empty or guard the division with an if‑statement. |
| high | `inventory.py` | `apply_discount` computes `price * percent / 100` which yields the discount amount, not the final price. | Return `round(price * (1 - percent / 100), 2)` to apply the discount correctly. |
| high | `config.py` | Uses `yaml.load` without specifying a loader, which can execute arbitrary code on malicious YAML input. | Replace with `yaml.safe_load(f)` or explicitly pass `Loader=yaml.SafeLoader`. |
| high | `shell_utils.py` | Executes shell commands directly (not shown) which can lead to command injection, especially when handling paths with spaces. | Use the `subprocess` module with `list` arguments and `shlex.quote` or avoid shell altogether. |
| medium | `tests/test_shell_utils.py` | The test expects `list_dir` to handle spaces, but the current implementation likely fails because it relies on naive string splitting. | Implement `list_dir` using `os.listdir` or `pathlib.Path.iterdir` to avoid shell parsing issues. |

**Optimization opportunities**
- Use list comprehensions for `total_price` and `average_price` to improve readability and speed
- Cache the result of `yaml.safe_load` if the same config is loaded repeatedly
- Replace manual rounding with `Decimal` for financial calculations to avoid floating‑point inaccuracies
- Add type hints to all functions for better maintainability

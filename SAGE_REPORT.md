## Code review

The repository provides a small inventory toolkit and configuration loader, but contains critical bugs and security flaws. The `total_price` function ignores item quantities, leading to incorrect totals, and `average_price` can raise a ZeroDivisionError on empty input. YAML loading uses unsafe `yaml.load`, and shell utilities execute commands without sanitization. Tests fail due to these logic errors and unsafe practices, and the code lacks proper error handling and documentation.

**Strengths**
- Simple, well‑named functions make the intent clear
- Small codebase is easy to navigate
- Tests cover basic functionality for shell utilities

| Severity | Location | Issue | Suggestion |
|---|---|---|---|
| high | `inventory.py` | `total_price` adds only `item["price"]` and ignores `item["qty"]`, producing wrong totals | Change the loop to `total += item["price"] * item.get("qty", 1)` and update docstring |
| high | `inventory.py` | `average_price` divides by `len(items)` without checking for an empty list, causing ZeroDivisionError | Return 0.0 when `items` is empty or guard the division with an if‑statement |
| high | `config.py` | Uses `yaml.load` without specifying a Loader, which can execute arbitrary code on malicious YAML | Replace with `yaml.safe_load(f)` or explicitly use `yaml.load(f, Loader=yaml.SafeLoader)` |
| high | `shell_utils.py` | Executes shell commands directly (e.g., via `os.system` or `subprocess`) without input sanitization, opening command injection risks | Avoid shell=True; use `subprocess.run` with a list of arguments and validate/escape paths |
| medium | `inventory.py` | `apply_discount` calculates discount as `price * percent / 100` which returns the discount amount, not the final price | Return `round(price * (1 - percent / 100), 2)` to reflect discounted price |
| low | `inventory.py` | Functions lack type hints and docstring parameter specifications, reducing maintainability | Add type annotations and expand docstrings to describe expected input structures |

**Optimization opportunities**
- Use generator expressions with `sum` for `total_price` to avoid explicit loops
- Cache the result of `len(items)` in `average_price` when list is large
- When loading config, open the file with `with open(path, 'r', encoding='utf-8')` to avoid default encoding issues

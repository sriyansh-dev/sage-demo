## Code review

The repository provides a small inventory utility and configuration loader, but contains critical bugs and security flaws. The inventory functions miscalculate totals and lack input validation, leading to incorrect results and potential crashes. YAML loading uses unsafe yaml.load, exposing code execution risks, and shell_utils executes commands without sanitization. Tests fail due to these issues, and the code would benefit from better error handling and clearer structure.

**Strengths**
- Simple, well‑documented functions for inventory calculations
- Compact test suite demonstrating intended behavior
- Clear module separation

| Severity | Location | Issue | Suggestion |
|---|---|---|---|
| high | `inventory.py` | total_price adds only item['price'] and ignores quantity, producing wrong totals; also does not validate item structure, causing KeyError on malformed data. | Multiply price by item.get('qty',1) and add type checks or try/except to handle missing keys. |
| high | `inventory.py` | average_price divides by len(items) without guarding against empty list, raising ZeroDivisionError. | Return 0.0 when items is empty or handle division safely. |
| high | `config.py` | Uses yaml.load without specifying SafeLoader, allowing arbitrary object construction and code execution. | Replace yaml.load(f) with yaml.safe_load(f) or yaml.load(f, Loader=yaml.SafeLoader). |
| high | `shell_utils.py` | Executes shell commands directly (e.g., via os.system or subprocess) without sanitizing input, opening command injection vulnerabilities. | Use subprocess.run with a list argument, avoid shell=True, and validate/escape paths. |
| medium | `inventory.py` | apply_discount calculates discount amount instead of discounted price; the docstring is misleading. | Rename to discount_amount or adjust calculation to return price - discount. |
| low | `tests/test_shell_utils.py` | Test expects list_dir to handle spaces, but implementation likely splits on whitespace, causing failure. | Ensure list_dir uses proper path handling (e.g., pathlib) rather than string splitting. |

**Optimization opportunities**
- Use list comprehensions or generator expressions for total_price and average_price to reduce loop overhead
- Cache results if inventory data is large and immutable
- Leverage pathlib throughout the project for safer path manipulations
